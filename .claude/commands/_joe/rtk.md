# RTK Stats

Run the following based on $ARGUMENTS (default: all three):

- `gain` → `rtk gain --graph`
- `econ` → `rtk cc-economics`
- `audit` → `rtk hook-audit`
- `discover` → `rtk discover`
- (no args or `all`) → run gain + econ + audit in sequence

Present results inline. No preamble.
