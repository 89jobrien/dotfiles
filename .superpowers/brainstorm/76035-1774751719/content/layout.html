Vector Dashboard — Layout Direction

What should the dashboard emphasize? Pick the layout that best matches your mental model.

A

Pipeline View

Shows Vector as a data flow: Sources → Transform → Sink. Left panel lists active source files being watched. Center shows live event stream. Right shows sink output stats. Focus on what's moving through the pipeline right now.

Good for: monitoring, debugging ingestion issues

B

Project Activity View

Organizes events by project/cwd. Top bar shows total events by source (Claude Code, OpenCode, Codex). Main area: one card per repo, showing event volume, last active time, git branch. Click a project to drill in.

Good for: seeing which projects are most active, cross-project comparison

C

Analytics Dashboard

Timeseries charts showing event volume over time by source. Message type breakdown (user/assistant/tool/progress). Active hours heatmap. Session count and token estimates. Closer to a "metrics dashboard" than a file watcher.

Good for: understanding usage patterns, historical trends
